Faculty guide / Quickstart

Your first quiz, with AI.

Copy the prompt below into your AI agent. It will guide you through five steps: launch your own demo, try it in Gradescope, then create your first real quiz.

Before you start

An AI coding agent (Codex, Claude Code, or Google Antigravity) • A free Cloudflare account • Gradescope access with Programming Assignments. No coding experience or prewritten questions needed.

Start here: paste this into your agent

Set up https://github.com/inouye-lab/oralscale for my course. I have no coding experience. Ask my course name and term. Read AGENTS.md and the README Quickstart; follow the existing tools to create my private course and deploy its demo-quiz on my Cloudflare account. Guide my sign-ins and Gradescope setup. Give me the quiz link, my quiz key, matching autograder zip and exact settings. Help me test through to a Gradescope grade and fix issues. Keep secrets and question banks private. Then interview me about learning goals and exclusions before generating questions from my teaching materials.

Get OralScale on GitHub · Full setup Quickstart · Question-design guide

  1. 1

    Open OralScale in your AI agent

    Paste the prompt above and answer the agent’s questions about your course name and term. Let it check or install the required tools; you do not need to know the commands.

  2. 2

    Launch your own demo course and website

    Let the agent create your private course with its built-in demo-quiz, then deploy the quiz website to your Cloudflare account. Complete the account sign-in when prompted. The agent prepares your quiz link and grading package.

  3. 3

    Connect your Gradescope course

    Create a Programming Assignment for demo-quiz and upload its matching autograder .zip. Use the container size the agent reports and a 40-minute timeout. The agent can walk you through the account steps.

  4. 4

    Try it all the way through

    Use the demo link and your own quiz key. Record, download, and upload to Gradescope. Check the resulting grade and feedback. If anything fails, tell the agent what happened and ask it to diagnose and retest.

  5. 5

    Generate your bank and launch Quiz 1

    Give AI your slides, transcripts or notes. Have it interview you about learning goals and exclusions, then generate a large bank from those sources. Review samples aloud. Ask the agent to validate, deploy, package and test your first real quiz.

ORALSCALE / Faculty guide02 / QUESTIONS & ANSWERS

A little more guidance

Good questions. Clear answers.

You bring the teaching goals. Your AI agent helps you build, test, and improve the course.

01

Do I need coding experience? Can I use a chat assistant?

No coding experience is required. An agent with file and command access can perform setup. A text-only chat assistant can explain steps and draft questions, but needs execution tools to set up your course.

02

What should my question-design specification say?

Have AI interview you about recall, concept application, theoretical reasoning, transfer across domains, or translating word problems into concrete models. Specify audience, difficulty, answer time and evidence of understanding. Exclude unsuitable tasks, such as untaught topics, lengthy calculations, trick questions or required writing.

03

How do I generate a large, course-aligned bank?

Give AI your materials and design specification, starting from the recommended template. Request roughly 100 varied, source-grounded questions with reference answers and grading criteria. Have the agent validate them. Review samples across topics and difficulty, try several aloud, then approve and freeze the bank.

Bank-generation specification →

04

Do I need a website, paid hosting, or an AI grading account?

A free Cloudflare account provides hosting; no existing website or custom domain is needed. You need Gradescope Programming Assignment access. Default grading needs no external AI key. Your setup agent may require a paid plan.

05

What if setup breaks, or I want a change?

Describe what you expected, what happened and the error shown. Ask the agent to diagnose, fix and retest without bypassing safeguards. Describe changes in ordinary language; you handle sign-ins and approve consequential changes.

06

Where does student work go?

Audio goes only to Gradescope. The quiz server receives the key, recording fingerprints and timings, not names, emails or audio. Identity checks and grade assignment run in Gradescope. Assessment uses a local AI model or an institution-approved external model receiving de-identified, redacted text. Keep course banks and credentials private.

07

How do approved extra-time accommodations work?

Students select approved extra time. Check claims manually, or download Gradescope submissions and run the working local audit script yourself against a local list of approvals. The list stays off Gradescope and out of the autograder. The script flags unsupported claims only when excess time was used; review flags before acting. Grades are not changed automatically. Keep audit files out of AI tools. After review, delete local approval lists, downloads and audit outputs, following institutional retention rules.

08

What should I check before students use a real quiz?

Test the deployed quiz through to a Gradescope grade with its matching autograder. Start with ungraded practice, share keys privately and provide the Student guide. Explain deadlines and which submission counts. Review flagged work and sample ordinary results.

Handle student records with care. You are responsible for FERPA compliance and your institution’s privacy, access and retention requirements when using OralScale. Ask your institution’s privacy office when unsure.

Gradescope help: Assignment setup & browser uploads · Submission history. Course policies take precedence. Privacy: FERPA guidance. Agent tools: Codex app · Claude Code desktop · Google Antigravity · Cloudflare Workers pricing
